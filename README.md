# BrightPath
A responsive tutoring centre website developed for BrightPath Tutoring Centre using HTML, CSS and JavaScript. The website provides information about tutoring services, subjects, tutors and contact details.
# BrightPath Tutoring Centre

## Project Overview

BrightPath Tutoring Centre is a fictional educational organisation that provides
academic support and tutoring services to learners.

This website was developed as a website project to create a professional,
user-friendly online presence for BrightPath Tutoring Centre.

The website provides visitors with information about the organisation,
available tutoring services, subjects, tutors and contact information.

---

## Project Purpose

The purpose of this project is to design and develop a responsive website
that:

- Introduces BrightPath Tutoring Centre.
- Provides information about tutoring services.
- Displays the subjects offered by the centre.
- Introduces the tutoring team.
- Allows learners and parents to make enquiries.
- Provides an easy-to-use and professional user experience.

---

## Target Audience

The main target audience for the website includes:

- School learners.
- Parents and guardians.
- Learners preparing for examinations.
- Students who require additional academic support.
- Learners who want to improve their academic performance.

### Home

### About

### Services

### Tutors

# BrightPath Tutoring Centre

## Project Overview

BrightPath Tutoring Centre is a responsive educational website designed to provide learners and parents with information about tutoring services and academic support.

The website aims to create a professional, user-friendly online presence for BrightPath Tutoring Centre. It provides information about the centre, available tutoring services, tutors and contact details.

## Project Objectives

The main objectives of the BrightPath Tutoring Centre website are to:

- Provide information about BrightPath Tutoring Centre.
- Display the tutoring services offered.
- Introduce tutors and their areas of expertise.
- Provide an easy way for learners and parents to make enquiries.
- Create a professional and responsive website.
- Improve the overall user experience through clear navigation and attractive design.

## Technologies Used

The following technologies were used to develop the website:

- HTML5
- CSS3
- JavaScript
- GitHub
- Visual Studio Code

## Website Pages

The website consists of the following pages:

### Home
The Home page introduces BrightPath Tutoring Centre and provides an overview of the services offered.

### About
The About page provides information about the tutoring centre, its purpose, mission and values.

### Services
The Services page displays the different academic support services provided by BrightPath, including:

- Individual Tutoring
- Small Group Classes
- Exam Preparation

### Tutors
The Tutors page provides information about the tutors and their areas of expertise.

### Contact
The Contact page allows learners and parents to contact BrightPath Tutoring Centre for enquiries and additional information.

### Images and Visual Content

The website includes images and visual elements to improve its appearance, communicate information clearly and create a more engaging user experience.

- **Homepage Image:** Added a classroom photograph to the home page to support the introduction to BrightPath Tutoring Centre.
- **Subject Images:** Added illustrations for Mathematics, English, Physical Sciences, Life Sciences, Accounting and Exam Preparation on the Services page.
- **Tutor Portraits:** Added photographic portraits from Unsplash to the Tutors page to make tutor profiles more visually appealing. These are stock images used as placeholders and do not necessarily represent actual BrightPath tutors.
- **Responsive Images:** Images are sized to fit different screen sizes, helping maintain a consistent layout on desktop, tablet and mobile devices.
- **Accessibility:** Added alternative text to images to help users understand their content when images cannot be displayed and to support assistive technologies.
- **Image Organisation:** Stored the subject illustrations and other local image assets in the website's `Assets` directory for easier organisation and maintenance.

These visual improvements help create a more professional, attractive and user-friendly website.
