# BrightPath
A responsive tutoring centre website developed for BrightPath Tutoring Centre using HTML, CSS and JavaScript. The website provides information about tutoring services, subjects, tutors and contact details.
# BrightPath Tutoring Centre

## Project Overview

BrightPath Tutoring Centre is a fictional educational organisation that provides
academic support and tutoring services to learners.

This website was developed as a website project to create a professional,
user-friendly online presence for BrightPath Tutoring Centre.

The website provides visitors with information about the organisation,
available tutoring services, subjects, tutors and contact information.

---

## Project Purpose

The purpose of this project is to design and develop a responsive website
that:

- Introduces BrightPath Tutoring Centre.
- Provides information about tutoring services.
- Displays the subjects offered by the centre.
- Introduces the tutoring team.
- Allows learners and parents to make enquiries.
- Provides an easy-to-use and professional user experience.

---

## Target Audience

The main target audience for the website includes:

- School learners.
- Parents and guardians.
- Learners preparing for examinations.
- Students who require additional academic support.
- Learners who want to improve their academic performance.

---

## Website Features

The website includes the following pages:

### Home
The home page introduces BrightPath Tutoring Centre and highlights
the main services and benefits offered by the organisation.

### About
The About page provides information about BrightPath's mission,
vision and approach to supporting learners.

### Services
The Services page presents the tutoring subjects and academic
support available to learners.

### Tutors
The Tutors page introduces the tutoring team and their areas of
academic support.

### Contact
The Contact page provides contact information and an enquiry form
for prospective learners and parents.
